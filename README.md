# SVEIRD

Возрастная пространственная SEIRD+V-модель: анализ стратегий вакцинации для Якутска.

Репозиторий подготовлен для одноимённой статьи, направляемой в «Сибирский журнал индустриальной математики». Авторы: Кычкина Б. Л., Тимофеева Т. С.

## Версии
Python 3.12.3, FEniCS 2019.2.0.64.dev0, numpy, scipy, matplotlib, pandas, openpyxl.

## Программы
- `model_core.py`: основная программа, отдельно её запускать не нужно. Считает эпидемию на квадрате 100×100 км для 7 возрастных групп и 6 состояний (S, V, E, I, R, D), пересчитывая их на каждом шаге по времени. Уравнения записаны в строках 180–206, остальное готовит данные и сохраняет результаты.
- `run_experiments.py`: все расчёты для таблиц статьи. Результаты записываются в CSV: `convergence_results.csv` (сходимость по сетке и по времени), `dose_equalized_strategies.csv` (три стратегии при одинаковом числе доз), `sensitivity_results.csv` (изменение β и γ на ±10 %).
- `make_figures.py`: рисунки статьи (суммарная динамика, кривые I(t) по возрастным группам, карты заражённых по области) и таблица `strategy_summary.csv`. Требует файла `dose_equalized_strategies.csv` из предыдущего пункта.
- `make_real_data.py`: из файла `data.xlsx` выбирает Республику Саха (Якутия), считает число активных случаев и сохраняет два ряда по 160 суток (`real_data_omicron2022.csv`, `real_data_delta2021.csv`).
- `run_verification_all.py`: сравнивает расчётное число заражённых I(t) при равномерной вакцинации с реальными рядами (корреляции Пирсона и Спирмена, пики), записывает `verification_summary.csv` и рисунки сравнения.

## Порядок запуска
1. Расчёты и рисунки: `python run_experiments.py`, затем `python make_figures.py`.
2. Сравнение с данными: `python make_real_data.py`, затем `python run_verification_all.py`. Этот блок не зависит от пункта 1.

Все файлы нужно держать в одной папке.

## Настройки шага по времени
В блоке `__main__` в конце `run_experiments.py` заданы `DT`, `OUT` и переключатели расчётов. Основные результаты получены при `DT = 0.125` (папка `results_dt0125`). Для сравнения стратегий при крупном шаге поставьте `DT = 0.5`, `OUT = 'results_dt05'` и отключите сходимость и чувствительность (`RUN_CONVERGENCE = False`, `RUN_SENSITIVITY = False`).

## Данные
Файл `data.xlsx` в репозиторий не включён. Используется набор А. Куприянова «COVID-19 in the Russian Federation» (ежедневные данные по регионам, 31.01.2020–15.05.2023): [https://github.com/alexei-kouprianov/COVID.2019.ru](https://github.com/alexei-kouprianov/COVID.2019.ru), DOI 10.20375/0000-0010-05BF-2. Скачайте файл с данными по регионам и положите его рядом с `make_real_data.py`.
